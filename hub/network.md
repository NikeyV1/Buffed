# 🌐 Buffed Network

Das Network bündelt die Buffed-Angebote hinter einer gemeinsamen Adresse:

## `buffed.mineserver.top`

Die Adresse verbindet dich mit dem **Network**. Den gewünschten Server wählst du anschließend in der Lobby.

## 🚪 Zum Strength SMP

1. Öffne Minecraft Java und gehe zu **Mehrspieler → Server hinzufügen**.
2. Trage `buffed.mineserver.top` als Serveradresse ein und verbinde dich.
3. Öffne in der Lobby den **Kompass** für die Serverauswahl.
4. Wähle **Strength SMP**.

Der Strength SMP ist aktuell **online**. Bei Fragen zum Zugang oder einer fehlenden Freischaltung hilft das Team im [Discord](https://discord.gg/MQzbpd4rju).

Lies die [Network Rules](/hub/network-rules.md). Die zusätzlichen [Strength-SMP-Regeln](/strength/rules.md) werden derzeit abgestimmt.

## ⚔️ Was bietet das Network außerdem?

**Duels** enthält BuffSMP-, Vanilla-SMP- und Strength-Duelle mit unterschiedlichen Auswahlmodi und Kits. Eigene Kits, Freunde, Partys und Zuschauerfunktionen ergänzen das System. Im Practice-Bereich ist Training mit Bots möglich, sofern es auf dem Server freigeschaltet ist.

> **Hinweis**
> Vanilla-SMP-Duelle sind ein eigener Duellmodus. Der frühere **Vanilla-Survival-Server ist offline**. Ebenso ist BuffSMP Season 7 beendet. Ihre Wikis bleiben als Archiv erreichbar.
