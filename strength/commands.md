# ⌨️ Befehle

`<Argument>` musst du angeben; `[Argument]` ist optional. Mit **Tab** ergänzt du Befehle und verfügbare Argumente.

## ⚡ Menü und Fortschritt

| Befehl | Funktion |
| --- | --- |
| `/strength` | Strength-Menü öffnen |
| `/strength menu` oder `/strength info` | Dasselbe Menü öffnen |
| `/strength class` | Klasse, Passive-Schwelle und Ultimate-Status anzeigen |
| `/strength ability` | Ultimate aktivieren, alternativ Shift+F |
| `/strength withdraw <Anzahl>` | Positive dauerhafte Strength als Splitter auszahlen |
| `/strength ritual` | Registrierte Ritualorte anzeigen; Start am Kern per Rechtsklick |
| `/strength ritual cancel` | Eigenes laufendes Ritual abbrechen |
| `/strength bounty` | Eigenen Wochenendauftrag anzeigen |
| `/strength help` | Kurzhilfe |

Aliase für `/strength`: **`/strengthsmp`** und **`/ssmp`**.

## 👥 Teams

| Befehl | Funktion |
| --- | --- |
| `/team` oder `/team list` | Teamübersicht |
| `/team create <Name>` | Team erstellen |
| `/team invite <Spieler>` | Als Leiter einen freien Online-Spieler einladen |
| `/team accept <Owner>` | Einladung des angegebenen Leiters annehmen |
| `/team leave` | Team als Mitglied verlassen |
| `/team disband` | Als Leiter das Team auflösen |
| `/team settings` | Aktuelle Teamoptionen anzeigen |
| `/team settings friendly-fire <on\|off>` | Team-Schaden ändern |
| `/team settings see-invisible <on\|off>` | Sichtbarkeit unsichtbarer Teammitglieder ändern |
| `/team help` | Team-Kurzhilfe |

Alias: **`/teams`**. Die Team-Unterbefehle sind außerdem über `/strength team …` erreichbar. [Team-Guide](/strength/teams.md).
